## Descrição do projeto
Este repositório contém o projeto S1_R1-AT1_PEND, que foi designado a estudantes do SENAI para desenvolver uma página de login para a empresa "Rápido e Seguro Logística".
A atividade foi desenvolvida com objetivo de testar responsividade, utilizando HTML, CSS  e BootStrap.

## Tecnologias utilizadas:

### HTML
O HTML é uma linguagem de marcação, que foi utilizada para desenvolver o esqueleto da página de maneira semântica, com header, main e footer. Com auxílio de bootstrap foi possível fazer grande parte da estilização sem utilizar css.

### CSS
O CSS é uma linguagem de estilização, que teve seu propósito em estilizações mais avançadas na página (como animações, medias queries específicos, cores específicas, etc).

### BootStrap
O BootStrap é uma biblioteca do CSS, que permite estilizações rápidas quando importado no HTML. Para importar o BootStrap é necessário pegar a tag ``<link>`` e ``<script>`` no site: https://getbootstrap.com/.
Para estilizar no HTML com bootstrap se coloca os valores da estilização dentro das valores da classe de cada elemento.

#### Exemplo bootstrap
``<main class="container min-vh-100 d-flex flex-column"><p>Exemplo</p></main>``
